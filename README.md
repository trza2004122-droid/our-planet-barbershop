# Our Planet Barbershop — V1 starter

واجهة عربية متجاوبة للحجز، بهوية أسود مطفي وفضي الشعار مع ذهبي شامبين مساعد.

## الموجود في هذه النسخة
- صفحة رئيسية وخدمات وفريق وحجز وتواصل.
- الخدمات والأسعار المقترحة والمدد المبدئية.
- الحلاقون: محمد، محمود، حسين، عمر.
- مواعيد العمل المعتمدة مبدئيًا: يوميًا 12 ظهرًا إلى 2 صباحًا.
- وضع معاينة محلي إذا لم يتم ربط Supabase.
- مخطط قاعدة بيانات Supabase ودالة حجز تمنع تداخل حجوزات الحلاق نفسه على مستوى قاعدة البيانات.

## مهم قبل التشغيل الفعلي
هذه **نسخة بداية تنفيذية وليست موقعًا منشورًا أو نظامًا جاهزًا لاستقبال حجوزات العملاء**. عند عدم ضبط Supabase، النموذج يسجل بيانات تجريبية في متصفح الجهاز فقط ولا يؤكد حجزًا حقيقيًا. لا تشارك رابط النسخة التجريبية مع العملاء على أنها تعمل.

## تشغيل المعاينة
1. فك ضغط الملف.
2. افتح مجلد المشروع في VS Code.
3. شغّل خادمًا محليًا من المجلد، مثل:
   `python -m http.server 8000`
4. افتح `http://localhost:8000`.

## ربط قاعدة البيانات
1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor وشغّل محتوى `supabase/schema.sql`.
3. انسخ Project URL و anon public key من إعدادات Supabase.
4. ضع القيمتين في أول ملف `app.js` بدل النصين الفارغين.
5. انشر الموقع على استضافة HTTPS بعد اختبار الحجز.

## ما لم يتم ربطه بعد
- لوحة إدارة آمنة بصلاحيات المالك والاستقبال والحلاقين.
- تسجيل دخول الإدارة وإدارة دوام الحلاقين والإجازات.
- عرض المواعيد المشغولة من قاعدة البيانات قبل الاختيار (التحقق النهائي من منع التعارض موجود في قاعدة البيانات عند الربط).
- بوابة الدفع الإلكتروني والتحقق من Webhook؛ خيار الدفع أونلاين معطّل عمدًا.
- سياسات الإلغاء والتعديل، الرسائل النصية، والتقارير.
- صور الحلاقين وروابط التواصل الاجتماعي النهائية.
